Without retrieval the UI guesses.

  • Multiple focal points compete at the same time, so the eye never settles.
  • Fake metrics and tiny helper text try to sell sophistication that the layout has not earned.
  • Color and chrome carry the experience while hierarchy stays vague.

With the skill it composes.

  • One hero, one action lane, and supporting proof arranged in a predictable reading rhythm.
  • Glass surfaces feel premium because contrast, spacing, and copy length stay under control.
  • The output is tied to sources and harness validation, so aesthetics stay reviewable instead of arbitrary.
