# Output Contract

The final output should be concise, but it must be actionable.

## Minimum structure

1. `Design thesis`
   One strong sentence describing the intended experience.
2. `Principle anchors`
   Which Google Design principles are steering the work.
3. `Style seeds`
   Which `awesome-design-md` samples are being fused and why.
4. `Style axes`
   Color, type, geometry, depth, rhythm, density, motion, and state treatment.
5. `Guardrails`
   What must not appear in the final UI.

## If the user wants implementation help

Add:

- recommended section breakdown
- component priorities
- content hierarchy
- motion guidance
- accessibility cautions

## If the user wants a critique

Add:

- strongest issues first
- what to remove
- what to simplify
- what to make explicit
- what to keep
